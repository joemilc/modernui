JKModernUI: MessageBox moderna e Toasts para Delphi VCL

**DESCRIÇÃO**

JKModernUI é uma biblioteca visual para Delphi criada para modernizar mensagens e notificações em projetos VCL.

Neste vídeo eu mostro uma MessageBox com visual mais atual, cantos arredondados, ícones contextuais, botões padronizados e suporte a arraste pelo header. Também apresento os Toasts da biblioteca, que são não-modais, possuem fechamento automático, várias posições na tela e também podem ser arrastados manualmente.

Recursos do projeto:
- MessageBox moderna para Delphi
- Toasts estilizados
- Cores inspiradas no padrão Bootstrap
- Ícones por tipo de mensagem
- Cantos arredondados
- API simples para integração
- Posicionamento configurável para os toasts
- Arraste manual das mensagens e dos toasts

Exemplos de uso:

```delphi
JKMUMessage('Aviso', 'Esta é uma mensagem primária.', jk_mtPrimary, jk_mbOK);
JKMUToast('Sucesso', 'Registro salvo com sucesso.', jk_mtSuccess, 4000, jk_tpRightTop);
```
